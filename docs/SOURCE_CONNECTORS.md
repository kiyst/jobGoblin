> **Restrictions / ToS column — read this first.** Every entry in the "Restrictions" column below is an **engineering/compliance risk consideration we drew up ourselves, not legal advice and not a categorical legal conclusion** about what any platform's Terms of Service actually prohibit or permit. Where we could reach a platform's current terms page during this pass, we link it directly so you can read the primary source yourself before building against that connector. Where an automated fetch was blocked (noted explicitly below), we say so rather than asserting what the page contains from memory or general reputation. Terms change and enforcement is inconsistent; re-check the linked page yourself at the time you actually build or ship a given connector, and involve counsel if the exposure is meaningful for how JobGoblin will be used.

## Open follow-ups

- `scrapinghub/extruct`'s license is now confirmed as BSD-3-Clause via the GitHub API (reviewed commit [`a31daaa`](https://github.com/scrapinghub/extruct/commit/a31daaadb82ec684b7d468d3b15734b8ae3b7265)) — the prior "unverified, commonly cited as BSD-3-Clause" flag is resolved and it can now be treated as at least a light dependency from a licensing standpoint.
- Verify the hosted `ats-scrapers` dataset's own terms of use/SLA before relying on it as a primary path rather than live scraping — still unverified as of this pass.
- Re-check JobSpy's Google/ZipRecruiter breakage status before building against those two specifically — they were reported non-functional (HTTP 403) as of the most recent evidence found (mid-2026) and may still be broken or may have been fixed since; the JobSpy repo's HEAD commit is unchanged since the last pass (2026-02-18), so no upstream fix has landed as of 2026-08-23.
- Workday connector reliability is the least uniform of the ATS-native connectors; budget for per-tenant fallback/escalation handling rather than assuming a single code path works everywhere.
- No dedicated, actively maintained Python/TypeScript typed API client for Greenhouse's or Lever's public Job Board API was found during the discovery pass (existing candidates were stale or targeted the wrong API) — a thin typed client is likely worth building in-house rather than depending on a third party.
- **New this pass:** Glassdoor's and ZipRecruiter's Terms-of-Use pages both returned HTTP 403 to our automated fetch attempts on 2026-08-23 (likely bot-blocking on their end rather than the pages being gone) — someone should open these manually in a browser and confirm/paste the current terms language before we rely on either connector at meaningful volume, since we could not do that verification ourselves in this pass.
